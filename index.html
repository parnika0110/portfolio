AI Opportunity Discovery Platform

OPPY

An AI-powered platform that helps students and early-career users discover, save and track opportunities.

Demoed at D-Day ↓

Live site · 25 Nov 2026

Live site · discovery step

Problem
Internships, jobs, hackathons, grants and more are scattered across the web — and so is tracking them.

Key contributions

  • Scheduled ingestion pipeline on AWS Lambda that normalises, de-duplicates and quality-filters opportunities
  • Natural-language and voice search with Sarvam AI
  • “Recommended for you” matching from each user’s interests
  • Saved list and application tracking, from Interested to Offer

Stack

  • Next.js 15
  • React 19
  • TypeScript
  • MongoDB
  • Sarvam AI
  • OpenAI
  • AWS Lambda
  • AWS Amplify
  • Tailwind CSS
  • Vitest

02 / 07 Currently building · Final Year Major Project

AI Healthcare Platform

MediAssist

An AI-assisted healthcare platform for prescriptions, medication and doctor appointments.

Problem
Prescriptions, medication schedules, symptoms and appointments are difficult to manage when they're scattered across different places.

Key contributions

  • Flutter and Firebase app with sign-in and Cloud Firestore data
  • Medication reminders and history, saved per user
  • Symptom-based health assessment
  • Doctor directory, appointment booking and a doctor dashboard
  • Python OCR service (FastAPI, OpenCV, PaddleOCR) that reads prescription photos and extracts each medicine’s dosage, frequency and duration — being connected to the app

Stack

  • Flutter
  • Dart
  • Firebase
  • Cloud Firestore
  • Python
  • FastAPI
  • PaddleOCR
  • OpenCV

Computer Vision · Touch-Free Dashboard

Gesture Controlled Infotainment System

A touch-free infotainment dashboard driven by real-time hand gesture recognition.

Technical highlights
  • Real-time hand-landmark tracking with MediaPipe Hands — in a Python + OpenCV prototype and in the browser
  • The index fingertip moves a pointer; a thumb–index pinch clicks and drags
  • Gesture-controlled music, navigation, calls and settings screens
  • Maps with Leaflet and OpenStreetMap, plus Nominatim search

  • OpenCV
